# CloudOpsHub

CloudOpsHub is a cloud-native business operations and document management
platform built for learning and demonstrating modern distributed-system
architecture using .NET, Angular, Blazor and AWS.

## Goals

- Modern .NET architecture
- Legacy .NET migration
- Angular Standalone
- Blazor
- SQL Server
- Redis
- Amazon S3
- Amazon SQS
- CQRS
- Saga
- Outbox / Inbox
- Microservices
- Docker
- AWS CDK
- GitHub Actions
- Observability
- Security
- AWS Solutions Architect Associate preparation
